# Security Policy

This repository contains **no** real account data, API keys, resumes or chat logs.
Everything under `data/` is generated locally at runtime and is git-ignored.

## Reporting a problem

- For a leaked secret or personal data: please use GitHub's **private security
  advisory** ("Report a vulnerability") instead of a public issue, so the details
  are not indexed.
- For ordinary bugs or selector breakage: open a normal issue, but **redact** any
  account name, phone number, candidate name, cookie or API key from logs/screenshots.

## Out of scope

Requests for bypassing platform risk control, CAPTCHA solving, or scraping personal
data at scale will not be supported. The project deliberately stops when a
verification challenge appears.
