猎聘人才寻访系统 · 使用说明

一次搜索定名单 → AI 打分排序 → 对最匹配的人主动沟通 → 自动索要联系方式 → 简历入库

版本 v1.0　·　2026-11-05　·　本机运行，数据不出本机

0开始前，请确认四件事

Windows 10 / 11目前仅支持 Windows
Python 3.10 或更新安装时勾选 “Add Python to PATH”
Google Chrome用系统自带的正式版即可
猎聘猎头端账号 + 模型 API KeyKey 在控制台「设置」里填
关于 API Key：系统用大模型给候选人打分，需要一个 OpenAI 兼容接口的 Key（DeepSeek / 通义 / Kimi / OpenAI 均可）。Key 只保存在您本机的 .env 文件，不会上传。

1三步启动

  1. 双击 install.bat —— 首次使用只做一次，会自动装好运行所需的组件（几分钟）。
  2. 双击 start.bat —— 会弹出一个 Chrome 窗口，请在这个窗口里登录您的猎聘账号，登录后保持窗口开着。
  3. 在浏览器打开 http://127.0.0.1:8898，就是操作界面。
直接打开控制台 →
顺序别反：一定要先有登录好的 Chrome，控制台才能连上。界面顶部状态条显示「浏览器已连接」才算就绪。那个黑色窗口是服务，使用期间不要关；用完关掉它即可停止。
首次必做：打开控制台后先点右上角「设置」，填入 API Key、模型名、接口地址（地址要带 /v1），点「测试连接」通过再保存。否则 AI 打分会提示「模型不可用」。

2界面上四块功能

功能作用
一键寻访选岗位、填搜索词和沟通数量 → 系统一次搜索、AI 打分、取前 N 名直接沟通。可填自定义话术、索要项。强烈建议先勾「预演」，确认名单无误后再正式跑，并把数量先改成 1。
检查环境确认浏览器登录态与猎聘页面结构正常；平台改版后先跑一次。
批量采集简历只采集「对方已回复手机号/微信」的会话，导出带头像的简历 PDF，并自动写入人才库。
人才库查看、搜索、标注已入库的候选人；「设置」里配置模型 API Key。
重要：正式寻访会真实发送消息，发出后无法撤回。界面上的橙色提示条会一直提醒这一点。建议一次不超过 10 人，避免平台风控。

3常见问题

现象处理
顶部显示「未检测到 Chrome」start.bat 没运行，或登录用的 Chrome 窗口被关了。重新运行一次并保持窗口打开。
岗位下拉是空的点控制台右上「设置」旁的刷新，或在猎聘页面确认「正在发布的职位」有数据；列表会自动缓存。
提示「模型不可用」点右上「设置」，填入 API Key、模型名、接口地址（地址要带 /v1），点「测试连接」再保存。
提示风控 / 要验证码立即停止操作，在 Chrome 里人工完成验证，隔一段时间再用，并降低单次数量。
端口被占用确认没有重复运行 start.bat；关闭多余的服务窗口后重试。

4数据与隐私

本仓库不含任何真实账号数据：没有登录态、没有 API Key、没有候选人简历、没有聊天记录、没有人才库数据库。所有这类文件都是您首次运行后，在您自己电脑上生成的，也只留在您自己电脑上。
  • 控制台只监听 127.0.0.1:8898，不对外网开放。
  • 采集结果落在 mvp/data/ 下，请按您公司的数据规范自行保管。
  • 候选人简历含个人信息，转发或归档前请先确认合规要求。
